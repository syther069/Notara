## Submission requirements
- A working prototype in a **public** repository. The README must match what runs.
  Claude Code and Codex do the first screening, then human judges decide.
- A public demo post on X that mentions NEAR HACKATHON, tags @NEARProtocol and #NEARHackathon, and has a video or screenshots.
- The submission form: project name, team lead, email, team size, tracks, NEAR wallet address, repo link, demo post link, and a 20–2000 character description.
- One submission per project. All code must be written after the announcement.

## Team rules for this repo
- No push, publish, mainnet deployment, spending real funds, social posts or submission without explicit approval from the project owner.
- Never present fixture or demo data as live evidence.
